# Check Figma Selection

Use the Figma MCP server to inspect the currently selected element(s) in Figma.

Steps:
1. Call the Figma MCP tool to get the current selection
2. Display the element's properties including:
    - Name and type
    - Dimensions (width, height)
    - Position (x, y)
    - Fill colors and styles
    - Text content (if applicable)
    - Auto-layout settings (if applicable)
3. Identify any potential implementation issues or improvements

Provide a clear, structured summary that helps translate the design into code.
